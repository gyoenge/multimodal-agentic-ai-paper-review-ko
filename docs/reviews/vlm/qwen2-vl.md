## 핵심 아이디어

Qwen2-VL의 출발점은 **해상도**이다. 제목에 담긴 "at Any Resolution"이 곧 논문의 주장이다.

그때까지 대부분의 VLM은 입력 이미지를 **고정된 크기로 리사이즈**했다. [LLaVA-1.5](llava-1-5.md)가 336px를, 그 확장이 격자 분할로 448px를 다루는 식이다. 이 방식에는 구조적 문제가 있다.

* 세로로 긴 문서나 가로로 넓은 파노라마를 정사각형에 우겨넣으면 **왜곡**이 생긴다
* 작은 글자가 빽빽한 문서는 리사이즈 과정에서 **정보가 소실**된다
* 반대로 단순한 이미지에도 항상 같은 수의 토큰을 쓰므로 **연산이 낭비**된다

사람은 이렇게 보지 않는다. 명함을 볼 때와 풍경을 볼 때 눈이 처리하는 정보량은 다르다. Qwen2-VL의 **Naive Dynamic Resolution**은 이 직관을 그대로 구현한다. **이미지 크기에 비례해 시각 토큰의 개수 자체가 달라진다.**

여기에 두 번째 축이 붙는다. 이미지와 비디오를 하나의 체계로 다루려면 **위치 정보를 어떻게 인코딩할 것인가**가 문제가 된다. 텍스트는 1차원, 이미지는 2차원, 비디오는 시간까지 더한 3차원이다. **M-RoPE(Multimodal Rotary Position Embedding)** 는 회전 위치 임베딩을 **시간·높이·너비 세 성분으로 분해**하여 세 모달리티를 하나의 좌표계 안에 통합한다.

그 결과 Qwen2-VL-72B는 여러 멀티모달 벤치마크에서 **GPT-4o 및 Claude 3.5 Sonnet과 경쟁하는 수준**에 도달했다. 가중치가 공개된 모델이 상용 최상위권과 어깨를 나란히 한 사례이다.

## 방법론

### Naive Dynamic Resolution

<!--Figure: Figure 1 (Qwen2-VL architecture with naive dynamic resolution)-->

핵심 변경은 ViT에서 일어난다. **원래의 절대 위치 임베딩을 제거하고 2D-RoPE로 대체**한다. 절대 위치 임베딩은 입력 크기가 고정되어야 성립하는 반면, RoPE는 상대적 위치를 인코딩하므로 **임의 크기의 입력을 다룰 수 있다.**

처리 과정은 다음과 같다.

1. 임의 해상도의 이미지를 리사이즈 없이 patch로 나눈다. patch 수는 이미지 크기에 따라 달라진다.
2. ViT가 2D-RoPE로 위치를 인코딩하며 처리한다.
3. **인접한 2×2 토큰을 MLP 하나로 묶어 단일 토큰으로 압축**한다(GELU 활성화). 시각 토큰 수를 4분의 1로 줄이는 단계이다.
4. 압축된 토큰 열의 앞뒤에 `<|vision_start|>`와 `<|vision_end|>` 특수 토큰을 붙여 LLM에 전달한다.

예컨대 224×224 이미지는 patch size 14 기준 16×16 = 256개 patch가 되고, 2×2 압축을 거쳐 64개 토큰이 되며, 특수 토큰 2개를 더해 **총 66개 토큰**으로 LLM에 들어간다. 이미지가 커지면 이 숫자도 함께 커진다.

추론 시에는 서로 다른 크기의 이미지들을 **하나의 시퀀스로 packing**하되, 전체 길이를 제한해 GPU 메모리 사용량을 통제한다.

> **참고 — 해상도 처리의 계보**: 고정 리사이즈에서 시작해, LLaVA-1.5가 **이미지를 격자로 잘라 각각 인코딩하는 타일링**으로 우회했고, Qwen2-VL은 **인코더 자체를 가변 입력에 대응하도록 바꿨다.** 타일링은 조각 간 맥락이 끊긴다는 부작용이 있었는데, 네이티브 방식은 이미지를 통째로 처리하므로 그 문제가 없다. **시각 토큰 수를 이미지가 담은 정보량에 비례시킨다**는 관점은 이후 InternVL 계열의 동적 해상도와 함께 표준이 된다.

<br/>

### M-RoPE

<!--Figure: Figure 2 (Multimodal Rotary Position Embedding)-->

LLM의 기존 1D-RoPE는 **1차원 위치만 인코딩**한다. 텍스트에는 충분하지만 이미지와 비디오에는 부족하다.

M-RoPE는 회전 위치 임베딩을 **temporal(시간), height(높이), width(너비)** 세 성분으로 분해하고, 모달리티마다 다르게 사용한다.

- **텍스트**: 세 성분이 **모두 동일한 position ID**를 쓴다. 결과적으로 기존 1D-RoPE와 기능적으로 동일해지므로, **사전 학습된 LLM과 호환성이 유지**된다.
- **이미지**: temporal ID는 상수로 고정하고, height와 width에 각 토큰의 이미지 내 2차원 위치를 부여한다.
- **비디오**: temporal ID가 **프레임마다 증가**하고, height/width는 이미지와 동일하게 처리한다.

여러 모달리티가 섞인 입력에서는, 각 모달리티의 position 번호가 **이전 모달리티의 최대 position ID에 1을 더한 값부터** 시작한다.

이 설계의 부수적 이점은 **외삽 능력**이다. 이미지와 비디오의 position ID 값이 1차원으로 나열할 때보다 작게 유지되므로, 추론 시 학습 때보다 긴 시퀀스로 확장하기가 수월해진다.

> **참고 — 하위 호환이 설계 조건이었다**: 텍스트에서 M-RoPE가 1D-RoPE로 **정확히 환원**된다는 점이 중요하다. 새로운 위치 인코딩을 도입하면서도 **사전 학습된 LLM의 언어 능력을 건드리지 않기 위한 조건**이다. Flamingo의 tanh 게이팅이 학습 시작 시점에 항등 함수가 되도록 만든 것과 같은 발상으로, **기존 능력의 보존이 새 능력의 도입보다 우선한다**는 원칙이 위치 인코딩에도 적용된 셈이다.

<br/>

### 이미지와 비디오의 통합 처리

Qwen2-VL은 이미지와 비디오를 **하나의 체계로 학습**한다.

- 비디오는 **2 FPS**로 샘플링한다.
- **3D 컨볼루션**으로 비디오를 처리하여, 2D patch가 아니라 **3D tube 단위**로 다룬다. 시퀀스 길이를 늘리지 않고도 더 많은 프레임을 담을 수 있다.
- **이미지는 동일한 두 장의 프레임으로 취급**하여 비디오와 형식을 일치시킨다.
- 각 프레임의 해상도를 동적으로 조절하되, 비디오 하나당 총 토큰 수를 **16,384개**로 제한한다.

<br/>

### 아키텍처와 학습

- **Vision Encoder**: 약 **675M 파라미터**의 ViT. DFN의 ViT를 기반으로 고정 위치 임베딩을 2D-RoPE로 교체했다. 특기할 점은 **2B, 7B, 72B 모든 모델이 동일한 ViT를 공유**한다는 것이다.
- **LLM**: Qwen2 계열(1.5B / 7B / 72B)

학습은 **3단계**로 진행된다.

1. **1단계**: LLM을 frozen한 채 **ViT만 학습**한다. 이미지-텍스트 쌍 중심으로 약 6000억 토큰을 사용한다.
2. **2단계**: **모든 파라미터를 unfreeze**하고 더 넓은 데이터로 학습한다. 약 8000억 토큰이 추가된다.
3. **3단계**: **ViT를 다시 frozen**하고 LLM만 instruction 데이터로 미세 조정한다(ChatML 형식).

사전 학습에 사용된 총 토큰은 **1.4조 개**이며, 데이터는 이미지-텍스트 쌍, OCR 데이터, 교차 배열된 이미지-텍스트 문서, VQA, 비디오 대화, 지식 데이터로 구성된다.

> **참고 — 무엇을 언제 얼리는가**: 학습 단계마다 frozen 대상이 바뀐다는 점이 흥미롭다. 1단계는 **시각 인코더를 언어 공간에 맞추는 데** 집중하고, 2단계는 **양쪽이 함께 적응**하게 하며, 3단계는 **언어 행동만 다듬는다.** BLIP-2가 정렬과 생성을 두 단계로 나눈 것, LLaVA가 projection만 먼저 학습한 것과 같은 계열의 사고이되, **전체를 함께 여는 구간을 중간에 둔다**는 점이 다르다.

<br/>

## 실험 결과

### 벤치마크 성능

<!--Figure: Table (Performance comparison with SOTA models)-->

- **Qwen2-VL-72B는 GPT-4o 및 Claude 3.5 Sonnet과 경쟁하는 성능**을 보이며, 다른 generalist 모델들을 앞섰다.
- **문서 이해에서 특히 강하다.** DocVQA, InfoVQA 등에서 SOTA를 기록했는데, 이는 네이티브 동적 해상도의 직접적 수혜 영역이다. 작은 글자가 빽빽한 문서일수록 리사이즈로 인한 정보 손실이 치명적이기 때문이다.
- **다국어 OCR**을 지원한다. 영어와 중국어뿐 아니라 대부분의 유럽 언어, 일본어, 한국어, 아랍어, 베트남어를 다룬다.
- **20분이 넘는 비디오**를 이해하고 질의응답, 대화, 콘텐츠 생성을 수행할 수 있다.
- **에이전트로서의 능력**을 강조한다. 복잡한 추론과 의사결정을 수행하며, 휴대폰이나 로봇과 연동해 **시각적 환경과 텍스트 지시에 근거해 자동으로 조작**할 수 있다. function calling과 UI 조작이 여기에 포함된다.

<br/>

### 모델 규모에 따른 경향

2B, 7B, 72B로 규모를 키울수록 성능이 **일관되게 향상**되었다. 특히 7B 모델이 이미지와 비디오 지원을 유지하면서도 경쟁력 있는 성능을 낸다는 점이 실용적으로 중요하다.

모든 규모가 **동일한 675M ViT를 공유**한다는 점은 시사적이다. 시각 인코더를 함께 키우지 않아도 LLM 규모만으로 성능이 오른다는 것은, 이 구성에서 **병목이 시각 인코딩이 아니라 언어 모델 쪽에 있었음**을 시사한다.

<br/>

### Ablation

- **동적 해상도 vs 고정 해상도**: 동적 방식이 성능이 더 좋으면서도 **평균적으로 더 적은 토큰**을 사용했다. 성능과 효율을 동시에 얻은 드문 경우이다.
- **M-RoPE vs 1D-RoPE**: M-RoPE가 우수했으며, 특히 **시퀀스가 긴 비디오 이해에서 격차가 컸다.** 시간 축을 별도 성분으로 분리한 효과가 프레임이 많아질수록 커지기 때문으로 해석된다.

<br/>

## 한계점

논문이 직접 밝히는 한계들이다.

- **비디오에서 오디오를 추출하지 못한다.** 비디오 이해가 전적으로 시각 정보에만 의존하므로, 말소리나 음향이 핵심인 장면은 다룰 수 없다. "비디오를 이해한다"는 표현이 실제로는 **연속된 프레임을 이해한다**는 의미에 가깝다.
- **지식 시점의 제약**: 학습 데이터가 2023년까지로 제한되어 이후의 사건이나 정보를 다루지 못한다.
- **복잡한 장면에서의 개수 세기가 부정확하다.** 객체가 많고 밀집한 상황에서 정확한 수를 세는 능력이 여전히 약하다. [CLIP](clip.md) 시절부터 지적된 counting 문제가 규모와 해상도 개선에도 불구하고 해소되지 않았음을 보여준다.
- **특정 기술 도메인에서 약하다.** 전기·기계 공학 같은 전문 영역의 도면이나 문서 이해에서 성능이 떨어진다.

이 외에 구조에서 따라오는 제약들도 짚어둘 만하다.

- **토큰 예산의 상한**: 비디오당 16,384 토큰이라는 제한이 있어, 긴 영상은 결국 프레임당 해상도를 낮추는 방식으로 타협해야 한다. **길이와 화질 사이의 트레이드오프**가 남는다.
- **2 FPS 샘플링의 한계**: 초당 2프레임으로는 빠른 동작이나 순간적인 변화를 놓칠 수 있다.
- **학습 데이터 비공개**: 가중치는 공개되었지만 1.4조 토큰의 학습 데이터 구성은 공개되지 않았다. 벤치마크와의 오염 여부를 외부에서 검증할 수 없다는 문제가 남는다.

<br/>

## 인사이트

- **입력 형식을 모델에 맞추는 대신 모델을 입력에 맞춘다**: 그간의 VLM은 이미지를 모델이 받아들일 수 있는 크기로 **변형**했다. Qwen2-VL은 반대로 **모델이 이미지를 있는 그대로 받도록** 바꿨다. 전처리로 해결하던 문제를 아키텍처로 옮긴 것이며, 그 결과 왜곡·정보 손실·연산 낭비가 한꺼번에 해소되었다. **파이프라인의 어느 단계에서 문제를 풀 것인가**에 대한 좋은 사례이다.
- **시각 토큰은 예산이고, 정보량에 비례해 배분되어야 한다**: 모든 이미지에 같은 토큰 수를 쓰는 것은 단순한 이미지에는 낭비이고 복잡한 이미지에는 부족이다. 동적 해상도가 **더 좋은 성능을 더 적은 평균 토큰으로** 달성했다는 ablation은 이 관점을 뒷받침한다. 고정 병목을 택한 Q-Former 계열과 대비되는 지점이기도 하다.
- **위치 인코딩이 모달리티 통합의 열쇠였다**: 텍스트·이미지·비디오를 한 모델에서 다루는 문제는 흔히 인코더나 연결자의 문제로 다뤄졌지만, Qwen2-VL은 그것이 **좌표계의 문제**임을 보였다. 세 모달리티가 하나의 위치 체계를 공유하되 각자 필요한 축만 사용하게 하는 M-RoPE는, 통합이 **추가가 아니라 분해로 이뤄질 수 있음**을 보여준다.
- **하위 호환은 설계 원칙이다**: M-RoPE가 텍스트에서 1D-RoPE로 정확히 환원되도록 만든 것은 Flamingo의 tanh 게이팅, BLIP-2의 2단계 학습과 같은 계보에 있다. **사전 학습된 능력을 보존하는 것이 새 능력을 얹는 것보다 먼저**라는 원칙이 반복해서 확인된다.
- **오픈 가중치가 상용 최상위권에 닿은 시점**: 72B 모델이 GPT-4o, Claude 3.5 Sonnet과 경쟁하는 수준에 도달했다는 것은, [CLIP](clip.md) 이후 이어져 온 오픈 계보가 **폐쇄형 모델과의 격차를 실질적으로 좁힌 지점**을 보여준다. 다만 학습 데이터는 여전히 비공개라, "공개"의 범위가 가중치에 한정된다는 점은 짚어둘 필요가 있다.
- **VLM에서 에이전트로**: 논문이 휴대폰·로봇 연동과 UI 조작을 전면에 내세운 것은, VLM의 목표가 **이미지를 설명하는 것에서 시각 정보에 근거해 행동하는 것으로** 옮겨가고 있음을 보여준다. 인식 모델과 에이전트의 경계가 흐려지는 흐름이며, 이는 GUI 조작 에이전트나 VLA 계열의 연구와 직접 맞닿는다.
