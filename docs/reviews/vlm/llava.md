## 핵심 아이디어

LLaVA의 기여는 아키텍처가 아니라 **데이터**에 있다. 핵심 질문은 "어떤 구조로 이미지와 언어를 이을 것인가"가 아니라, **"멀티모달 instruction 데이터를 어디서 구할 것인가"** 이다.

언어 분야에서는 이미 instruction tuning이 확립된 방법론이었다. 기계가 생성한 instruction-following 데이터로 학습시키면 처음 보는 태스크에 대한 zero-shot 능력이 크게 향상된다는 것이 InstructGPT 이후 반복적으로 확인되었다. 그러나 **멀티모달 영역에는 이 흐름이 아직 도달하지 않았다.**

이유는 데이터에 있다. 웹에는 image-text 쌍이 넘쳐나지만, 그것은 **캡션**일 뿐 **instruction**이 아니다. "이미지를 간단히 설명하라" 같은 질문을 붙여 기계적으로 확장할 수는 있으나, 이렇게 만든 데이터는 **다양성이 없고 깊이 있는 추론을 담지 못한다.** 사람이 직접 작성하자니 규모를 확보할 수 없다.

LLaVA는 여기서 역발상을 한다. **이미지를 볼 수 없는 language-only GPT-4를 교사로 쓰는 것**이다. 이미지를 직접 보여주는 대신 **캡션과 bounding box라는 기호적(symbolic) 표현으로 번역해서** 전달하면, GPT-4는 그 텍스트만으로도 풍부한 대화와 추론 데이터를 만들어낼 수 있다.

이렇게 생성한 **15.8만 개의 instruction 데이터**와, **선형 레이어 한 장**이라는 극도로 단순한 연결자만으로, LLaVA는 GPT-4 대비 상대 점수 **85.1%** 를 달성한다. 복잡한 연결 구조 대신 좋은 데이터에 베팅한 결과이다.

## 방법론

### GPT-4를 이용한 Instruction 데이터 생성

<!--Figure: Table 1 (One example to illustrate the instruction-following data)-->

가장 큰 난관은 GPT-4가 이미지를 볼 수 없다는 점이다. LLaVA는 이미지를 **두 가지 기호적 표현**으로 변환해 텍스트로 전달한다.

- **Caption**: 장면을 여러 관점에서 서술한 문장들
- **Bounding Box**: 각 객체의 개념과 **공간적 위치**를 함께 인코딩한 좌표 정보

캡션만으로는 "무엇이 있는지"는 알아도 "어디에 있는지"를 알 수 없으므로, bounding box가 공간 관계에 대한 질문을 생성할 수 있게 해준다. 여기에 사람이 직접 만든 소수의 seed 예시를 붙여 **few-shot in-context learning**으로 GPT-4를 유도한다.

COCO 이미지를 대상으로 **세 종류의 데이터**를 생성했다.

| 종류 | 규모 | 내용 |
|------|------|------|
| **Conversation** | 58K | 사진에 대해 묻고 답하는 다중 턴 대화. 객체의 종류·개수·행동·위치·상대적 위치 등을 다루며, **답이 명확히 정해지는 질문만** 포함 |
| **Detailed Description** | 23K | 이미지를 상세하고 포괄적으로 서술. 상세 설명을 요구하는 질문 목록에서 무작위로 샘플링 |
| **Complex Reasoning** | 77K | 단계적 논리를 요구하는 심층 추론 질문 |

총 **158K개의 고유한 language-image instruction-following 샘플**이 만들어졌다. ablation 결과 ChatGPT보다 **GPT-4가 확연히 높은 품질**의 데이터를 생성했다.

> **참고 — 왜 이 방식이 성립하는가**: 이 데이터 생성 파이프라인은 사실상 **GPT-4의 언어 능력을 시각 도메인으로 증류(distillation)** 하는 과정이다. GPT-4는 이미지를 본 적이 없지만, "테이블 위에 노트북과 커피잔이 있고 각각의 좌표는 이렇다"는 정보만 주어지면 **그 장면에 대해 사람이 물을 법한 질문과 답을 상상해낼 수 있다.** 시각 능력이 아니라 언어 능력을 빌려오는 것이므로 이미지를 못 봐도 문제가 되지 않는다.

### 아키텍처

<!--Figure: Figure 1 (LLaVA network architecture)-->

LLaVA의 구조는 의도적으로 단순하다.

- **Vision Encoder**: CLIP **ViT-L/14**
- **LLM**: **Vicuna** (13B / 7B) — 당시 오픈소스 LLM 중 instruction-following 능력이 가장 뛰어나다는 이유로 선택
- **Connector**: **학습 가능한 선형 레이어 $\mathbf{W}$ 한 장**

이미지 feature $\mathbf{Z}_v$에 $\mathbf{W}$를 곱해 언어 토큰 임베딩과 **동일한 차원의 visual token $\mathbf{H}_v$** 로 사영하고, 이를 텍스트 토큰과 나란히 LLM에 넣는다. 그게 전부이다.

논문은 이 단순함이 **의도된 선택**임을 명시한다. Flamingo의 gated cross-attention이나 [BLIP-2](blip2.md)의 Q-Former 같은 정교한 방식도 가능하지만, **연결자를 가볍게 유지해야 데이터 중심 실험을 빠르게 반복할 수 있기 때문**이다. 더 정교한 구조는 향후 과제로 남긴다.

<br/>

### 2단계 학습

**1단계 — Feature Alignment 사전 학습**

CC3M을 명사구 빈도 기준으로 필터링해 개념 분포를 균형 있게 맞춘 **595K 쌍**을 사용한다. 이를 단순 확장 방식으로 instruction 형태로 바꾼다(이미지를 간단히 설명하라는 질문을 무작위로 뽑고, 원래 캡션을 답으로 삼는 단일 턴 데이터).

이 단계에서는 **vision encoder와 LLM을 모두 frozen**으로 두고 **오직 projection 레이어 $\mathbf{W}$만** 학습한다. 사실상 frozen LLM이 알아들을 수 있는 **visual tokenizer를 훈련시키는 과정**이다.

**2단계 — End-to-End Fine-tuning**

**vision encoder는 계속 frozen**으로 두고, **projection 레이어와 LLM을 함께** 업데이트한다. 두 가지 시나리오로 실험했다.

- **Multimodal Chatbot**: 앞서 생성한 158K instruction 데이터로 학습
- **Science QA**: ScienceQA 데이터셋으로 학습

학습 비용은 매우 낮다. **A100 8장** 기준으로 1단계는 595K 데이터에 대해 약 4시간, 2단계는 158K 데이터에 대해 약 10시간이면 끝난다.

## 실험 결과

### 평가 방식: GPT-4를 심판으로

개방형 멀티모달 생성은 정답이 하나로 정해지지 않아 기존 지표로 평가하기 어렵다. LLaVA는 **GPT-4를 심판(judge)으로 쓰는 방식**을 도입했다.

GPT-4에게 이미지의 텍스트 표현(캡션 + bounding box)을 참조 자료로 주고, LLaVA의 답변을 **text-only GPT-4가 생성한 답변과 비교**하도록 한다. 도움이 되는 정도, 관련성, 정확성, 상세함을 1~10점으로 채점하게 한 뒤 **상대 점수**로 환산한다.

두 개의 벤치마크를 함께 제안했다.

- **LLaVA-Bench (COCO)**: 30개 이미지, 각 3개 질문(대화·상세 설명·복잡 추론) = 90개 질문. 주로 데이터 구성에 대한 ablation에 사용
- **LLaVA-Bench (In-the-Wild)**: 24개 이미지, 60개 질문. 실내외 장면뿐 아니라 **밈, 회화, 스케치**까지 포함하여 새로운 도메인에 대한 일반화를 시험

<br/>

### 멀티모달 대화 성능

- **LLaVA-Bench (COCO)**: LLaVA는 GPT-4 대비 **85.1%** 의 상대 점수를 기록했다. 데이터 종류별 ablation에서는 세 종류를 모두 쓸 때가 가장 좋았고, 특히 **complex reasoning 데이터가 성능 향상에 크게 기여**했다.
- **LLaVA-Bench (In-the-Wild)**: LLaVA가 **67.3%** 를 기록하며 BLIP-2를 29%, OpenFlamingo를 48% 앞섰다. 격차가 COCO보다 오히려 더 벌어졌는데, 이는 instruction tuning이 **낯선 도메인에서의 지시 수행 능력**에 특히 크게 작용함을 보여준다.

BLIP-2와 OpenFlamingo가 이미지를 잘 묘사하면서도 **사용자의 지시에 맞춰 답하지 못하는** 경향을 보인 반면, LLaVA는 질문의 의도에 맞게 응답했다. 시각 인식 능력과 지시 수행 능력이 별개의 축임을 드러내는 결과이다.

<br/>

### ScienceQA

- LLaVA 단독으로 **90.92%** 를 기록했다. 참고로 사람의 정확도는 88.4%이다.
- GPT-4와 결합하는 방식을 실험했는데, 두 모델의 답을 병치해 보완하는 방식이 **92.53%** 로 당시 새로운 SOTA를 달성했다.

ablation에서 확인된 사항들이다.

- **마지막 레이어보다 뒤에서 두 번째 레이어의 feature가 더 좋았다.** 마지막 레이어는 전역적·추상적 속성에 집중하는 반면, 그 직전 레이어는 **이미지의 구체적 디테일을 이해하는 데 유용한 국소적 속성**을 더 많이 담고 있기 때문으로 해석된다.
- 답을 먼저 내고 추론을 붙이는 방식은 성능이 더 나빴다.
- 13B가 7B보다 우수하여 모델 규모의 효과가 확인되었다.

<br/>

## 한계점

- **벤치마크 규모가 매우 작음**: LLaVA-Bench는 90개, 60개 질문에 불과하다. 통계적으로 견고한 비교를 하기에는 표본이 지나치게 적어, 보고된 점수 차이를 그대로 신뢰하기 어렵다.
- **평가의 순환성**: 학습 데이터를 생성한 모델(GPT-4)이 평가까지 담당한다. 심판이 자신의 출력 스타일과 유사한 답변을 선호할 가능성을 배제할 수 없어, **평가가 구조적으로 편향될 소지**가 있다. 게다가 심판 역시 이미지를 직접 보지 못하고 텍스트 참조 자료에만 의존한다.
- **학습 데이터에 내재된 오류**: GPT-4는 이미지를 본 적이 없으므로, 캡션과 bounding box에 없는 내용을 상상해 넣을 수 있다. 이렇게 생성된 **hallucination이 그대로 학습 데이터가 되어 모델에 전이**된다.
- **Hallucination과 "bag of patches" 문제**: 논문 스스로 제시한 예시에서, 냉장고 사진을 보고 딸기맛 요거트가 있는지 물으면 실제로는 없는데도 있다고 답한다. 이는 모델이 개별 패치의 정보를 나열할 뿐 **복잡한 의미 관계를 온전히 파악하지 못하는 경우**가 있음을 보여준다.
- **단일 이미지 한정**: 여러 장의 이미지나 비디오를 다루지 못하며, 이미지 간 관계를 요구하는 태스크에는 적용할 수 없다.
- **해상도의 제약**: CLIP ViT-L/14의 224 해상도를 그대로 쓰므로, 문서 이해나 정밀한 OCR처럼 **고해상도 디테일이 필요한 태스크에는 근본적으로 취약**하다.
- **학술 벤치마크에서의 검증 부족**: 대화 능력에 초점을 맞춘 탓에 VQA 등 기존 학술 벤치마크에 대한 폭넓은 검증이 이뤄지지 않았다. 이 부분은 이후 [LLaVA-1.5](llava-1-5.md)에서 학술 태스크 데이터를 추가하며 보완된다.

## 인사이트

- **아키텍처가 아니라 데이터가 병목이었다**: 같은 시기 BLIP-2는 Q-Former와 2단계 사전 학습이라는 **정교한 구조**에 1억 2900만 쌍을 투입했다. LLaVA는 **선형 레이어 한 장**에 15.8만 개의 잘 만들어진 데이터를 투입했다. 지시 수행 능력에서 후자가 앞섰다는 사실은, 당시 멀티모달 모델의 실질적 병목이 **연결 구조가 아니라 학습 데이터의 성격**이었음을 보여준다. 이후 LLaVA-1.5가 MLP와 더 많은 데이터만으로 SOTA를 갱신하면서 이 관점은 더욱 굳어졌다.
- **모달리티를 기호로 번역해 LLM의 능력을 빌려오기**: 이미지를 캡션과 좌표로 바꿔 language-only 모델에 먹인다는 발상은, **강력한 단일 모달 모델의 능력을 다른 모달리티로 옮기는 일반적 레시피**가 되었다. 교사 모델이 해당 모달리티를 직접 다루지 못해도, 적절한 기호적 표현만 있으면 데이터 생성이 가능하다.
- **합성 데이터가 사람의 annotation을 대체하기 시작한 지점**: [BLIP](blip.md)의 CapFilt가 모델로 캡션을 만들어 데이터를 정제했다면, LLaVA는 더 나아가 **더 강한 모델로부터 완전히 새로운 형태의 데이터(대화·추론)를 만들어냈다.** 사람의 라벨링 없이 고차원 능력을 이식할 수 있음을 보인 사례로, 이후 대부분의 오픈소스 멀티모달 모델이 이 방식을 따랐다.
- **인식과 지시 수행은 다른 능력이다**: BLIP-2가 이미지를 잘 묘사하면서도 사용자의 질문 의도에는 어긋난 답을 내놓는 현상은, **잘 보는 것과 요구대로 답하는 것이 분리된 축**임을 보여준다. 멀티모달 모델의 평가가 캡션 품질에서 지시 수행 능력으로 옮겨가는 계기가 되었다.
- **LLM-as-a-judge 평가의 확산**: 개방형 생성에 대해 GPT-4를 심판으로 쓰는 방식은 이후 멀티모달 벤치마크의 사실상 표준이 되었다. 순환성이라는 약점을 안고 있음에도, **정답이 하나로 정해지지 않는 태스크를 정량화할 현실적 대안**이 마땅치 않다는 점에서 널리 채택되었다.
- **접근성이 만든 생태계**: A100 8장으로 하루면 학습이 끝나고 데이터·코드·체크포인트가 모두 공개되었다는 점이 결정적이었다. LLaVA는 하나의 모델이라기보다 **오픈소스 VLM 연구의 공통 출발점**이 되었고, 이후 LLaVA-1.5, LLaVA-NeXT를 비롯해 수많은 파생 연구의 기반이 되었다.
